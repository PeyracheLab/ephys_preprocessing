# ---------------------------------------------------------------------------
# STEP 1 -- Find out what your computer needs
# ---------------------------------------------------------------------------
# Open a terminal:
#   Windows -> press Start, type "cmd", open Command Prompt (or PowerShell)
#   Linux   -> open your normal Terminal app
#
# Type this and press Enter:
#
#     nvidia-smi
#
# CASE A: you get an error ("command not found" / "not recognized")
#   -> Your computer has no NVIDIA GPU, or no driver installed.
#   -> Go to the "CPU ONLY" block near the bottom, uncomment that ONE line,
#      then skip to STEP 3.
#
# CASE B: it prints a table
#   -> Look at the top-right corner for a line like:
#          CUDA Version: 12.1
#   -> Write that number down. This is the HIGHEST CUDA version your driver
#      can run -- NOT something you need to separately install.
#
# ---------------------------------------------------------------------------
# STEP 2 -- Pick your torch block
# ---------------------------------------------------------------------------
# Find the block whose number is the CLOSEST match that is LESS THAN OR
# EQUAL TO the number nvidia-smi gave you. Examples:
#
#     nvidia-smi says "CUDA Version: 12.1"  -> use the CUDA 12.1 block
#     nvidia-smi says "CUDA Version: 12.3"  -> use the CUDA 12.1 block (closest ≤ 12.3)
#     nvidia-smi says "CUDA Version: 12.5"  -> use the CUDA 12.4 block
#     nvidia-smi says "CUDA Version: 12.7"  -> use the CUDA 12.6 block
#     nvidia-smi says "CUDA Version: 11.8"  -> use the CUDA 11.8 block
#
# Rule of thumb: if you're not sure, ROUND DOWN, never up. A lower number
# will always work on a newer driver; a higher number might not.
#
# Then UNCOMMENT BOTH LINES of that one block (delete the leading "# ").
# Leave every other block commented out. Only ONE block should be active.
# Currently, the torch for CUDA 12.1 is the only un-commented one. If you 
# choose a different one, make sure to comment out the CUDA 12.1
